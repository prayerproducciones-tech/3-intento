# Prayer Producciones

Sitio web oficial de Prayer Producciones - Creando contenido con propósito.

## 📁 Estructura del Proyecto

```
├── prayer11 copy.html      # Sitio principal
├── LOGO PRAYER WEB 2.png   # Logo
├── Prayer Primer ADS 16.9.mov # Video principal
├── reels/                  # Videos de reels (10 videos)
├── flyers/                 # Diseños de flyers (8 imágenes)
├── fotografia/             # Fotografías (15 imágenes)
├── videos-musicales/       # Videos musicales (vacío)
└── branding/              # Materiales de branding (vacío)
```

## 🚀 Características

- Portafolio dinámico con carrusel interactivo
- Secciones: Servicios, Portafolio, Planes, Instagram
- Diseño responsivo para dispositivos móviles y desktop
- Fotografías en orden aleatorio
- Videos y contenido multimedia

## 📱 Responsive Design

Optimizado para:
- 16:9 (Desktop)
- 9:16 (Mobile)

## 🔧 Tecnologías

- HTML5
- Tailwind CSS
- GSAP (Animaciones)
- Swiper (Carruseles)
- Elfsight (Feed de Instagram)

## 📝 Notas

- El sitio se deploya automáticamente a GitHub Pages al hacer push
- Los videos y fotos se organizan por carpetas
- Las fotografías se muestran en orden aleatorio
